# 현재 3개월 목표의 후속 탐색

2026-09-08. 기준 커밋 `b3e80bf`의 69개 개발 설정과 후속 평가가 채택 기준을 통과하지 못한 뒤 진행한다. 이전 회차는 데이터 검증·신규 모델·실제 계좌 평가를 완료한 진전으로 분류한다. 아직 금융 목표를 달성하지 못했으며, 같은 시장 역사를 이미 여러 모델로 본 상태임을 유지한다.

## 기존 EMA 추세 전략

후속 진단은 결과를 보기 전에 진입 간격 0.3%의 세 조합으로 고정한다. 기본값은 12·26이다. 이전과 같은 개발·검증·확인 기간 및 계좌 목표·낙폭 중단·비용·거래량 규칙을 쓴다. 기본 시드는 204이며 성공 후보가 생기면 다른 시드도 검증한다.

## 분기 실적

현재 입력에는 2026년 2분기 자료가 일부 있지만 과거 종목별 연속 8개 분기의 확보 여부가 불균일하다. 우선 현재·역사적 종목군의 자료 충족률을 확인한다. 가능한 경우 DART 다중회사 주요계정의 분기·반기·사업보고서 원문을 추가 수집해 과거 상위 50종목의 합집합 전체를 보완한다. 원문 수집에 성공했다는 이유만으로 당기액·누적액·연결·별도·정정 접수일의 의미가 검증됐다고 간주하지 않는다.

기존 `earnings-acceleration-rank`는 연속 8개 단독 분기 영업이익과 양의 가격 모멘텀을 요구한다. 누적액을 단독 분기 이익으로 혼동하지 않고, 차분에 필요한 두 보고서가 모두 공개된 뒤에만 파생 수치를 노출한다. 최신 정정 자료를 원래 공시일로 소급하지 않는다. 자료가 부족하면 그 상태를 기록하며 무자료 결과를 전략 성과로 판정하지 않는다. 이익 전략의 구체적 후보는 데이터 검증 후 성과 계산 전에 별도로 고정한다.

현재 환경 비교 조건과 채택 기준은 앞선 사전 규칙을 유지한다. 더 많은 조합을 탐색했다는 이유로 통계적 근거가 강해졌다고 해석하지 않는다.

## 분기 실적 후보 고정

성과를 계산하기 전 8분기·공개시점·동일 회계기준만 검사했다. 첫 자료 충족 시작점은 2018-04-02다. 개발 46개 시작점 중 자료 보유 종목이 하나 이상인 것은 19개, 절반 이상인 것은 13개다. 검증은 각각 45/45와 37/45, 최근 확인은 29/29와 29/29다. 최소·최대 충족 종목 수는 검증 19~34, 확인 28~43이다. 자료가 없는 초기 구간을 전략 실패나 성공의 근거로 삼지 않는다.

기존 이익 가속 순위를 수정하지 않고 `priceMomentumDays` 60·126·252 × `topN` 3·5·8의 9개 설정을 개발한다. 종목군 갱신 20봉, 공시 지연 허용 2분기, 같은 회계기준의 연속 8개 분기를 고정한다. 기본 후보는 126일·5종목이다. 후속 진단은 60일·5, 126일·3/5/8, 252일·5의 5개로 미리 정한다. 현재 금리·유가 정보를 보고 임의로 실적 업종을 넣거나 기존 순위를 바꾸지 않는다.

원래 달력 구간 전체 결과를 보존하고, 별도로 시작 시점 종목군의 50% 이상이 8분기 자료를 갖춘 구간을 표시한다. 이는 수익을 보지 않고 정한 자료 충족 진단이며 다른 전략과 공정하게 비교할 때 같은 날짜를 쓴다. 초기 자료 부족으로 개발 표본이 짧아진 한계를 보고한다. 기존 검증·확인 기간과 비용, 계좌 목표·중단, 기업행위 제외 규칙을 유지한다.

누적 차분과 원문의 당기 분기액 간 100만원 이내 차이만 반올림 오차로 허용한다. 더 큰 불일치·누적액 누락·동일 기준의 직전 보고서 누락은 제외한다. 4분기는 사업보고서 연간액에서 3분기 보고서 9개월 누적액을 차감하고 두 접수일 중 늦은 날짜 다음 날부터 사용한다. 최신 API 빈티지라 원래 공시가 정정본으로 대체된 종목의 과거 정보가 없어질 수 있다.

DART는 이번 2015년 분기·반기 요청에 `013`(자료 없음)을 반환했고 2015년 사업보고서만 존재했다. 따라서 2015년 4분기도 9개월 누적액을 차감할 수 없어 만들지 않았다. 첫 정상 분기는 2016년 1분기이며, 연속 8분기·공개일을 적용하면 위의 2018년 시작 제한이 생긴다. API 문서의 2015년 이후 지원 범위를 모든 분기의 실제 존재로 간주하지 않았다.
