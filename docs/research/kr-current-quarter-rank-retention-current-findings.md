# 보유 순위 완충 후보의 현재 신호 확인

2026-09-09 작성, 현재 관찰 기준은 2026-09-08 종가다. 기준 커밋 `b99ed01` 뒤 새 후보 `rank-retention-momentum`을 현재 신호 계산기에 연결했다. 이전 계산기는 이 연구 전략을 조회할 수 없었으며, 앞서 관찰한 다섯 종목은 기존 횡단면 모멘텀의 결과였다.

**새 후보를 직접 실행해도 다섯 종목은 같았다. 현재 매수 주문은 0건이며 종목 선정 단계다.** 기본 20일·5종목·20봉·유지 10위와 현금 1억원을 사용했다. 현재 신호의 재현을 완료한 것이며 3개월 수익이나 실전 전략 채택을 확인한 결과는 아니다.

## 현재 조건과 선정 종목

월별 규칙에 따라 8월 31일 선정한 200종목을 유지했다. 9월 8일 코스피의 20일 연율 변동성은 45.45%, 20일 수익은 +10.40%, 종가는 6,954.52로 20일 평균 6,760.334보다 높다. 고정한 30% 변동성·양수 수익·이동평균 위 조건은 모두 충족한다. 60일 수익 −14.39%도 함께 보존한다. 이는 저장된 시장 입력의 조건 대조이며 국제 정세·물가·금리의 영향을 정량적으로 예측한 값은 아니다.

각 목표의 실제 21개 일봉으로 수익률을 다시 계산해 전략 점수와 대조했다. 현재 순위 경계에는 동점이 없었다. 가온전선의 6월 30일 미확인 사건도 지우지 않았고, 현재 점수에 쓰인 가격 창은 해당 사건을 가로지르지 않는다. 현재 입력의 전체 이력 제한 10건을 그대로 유지했다. 이 확인이 과거 사건 자체의 해명을 대신하지는 않는다.

현재 계좌는 전액 현금이므로 보유 종목 유지 규칙이 최초 순위에 영향을 주지 않는다. 보유 상태가 있는 계좌의 다음 교체 결과가 기존 모멘텀과 같다고 일반화하지 않는다. 거래 종목과 수량을 확정한 주문표로 사용하지 않는다.

## 판단과 체결 시점

현재 신호 계산은 관찰일의 종목 선정만 수행한다. 다음 거래 봉의 종가에서 자격·가격·현금을 다시 확인해 매수 주문을 판단하고, 체결은 그 이후 거래 봉에서 가능하다. 향후 가격과 실제 거래일 자료를 이번 입력에 생성하지 않았다.

합성 가격을 사용한 별도 테스트에서는 실제 분기 엔진의 이력 제한·목표 미달 후 재개·계좌 위험 규칙을 감싼 전략으로 이 순서를 확인했다. 선정 봉에서는 주문이 없고, 다음 거래 봉에서 매수 의도가 발생하며, 그 다음 봉에서만 다섯 건이 체결됐다. 합성 봉의 결과를 앞으로의 실제 가격이나 체결로 표시하지 않는다.

현재 CLI는 신규 현금 계좌의 관찰 도구다. 고변동 반등 진입 조건은 감사 단계에서 별도로 대조한다. 기존 계좌의 포지션·최고점·재개 상태·만기 운용이나 운영 주문 기능을 대신하지 않는다.

## 코드 변경과 검증

현재 신호 계산을 호출 가능한 함수와 CLI로 분리하고 새 연구 전략의 분기를 추가했다. 기준일이 입력 거래일에 없거나 미래 가격이 포함되면 실행을 거부한다. 현재 일봉이 없는 종목도 조용히 이전 가격으로 선정하지 않으며, 당일 거래정지가 확인된 경우에만 결손을 허용하고 신규 대상에서 제외한다.

현재 신호 6개 테스트, 보유 순위·재개·이력 제한 테스트를 포함한 4개 파일·25개 테스트가 통과했다. 변경 TypeScript·테스트의 ESLint와 서버 타입 검사를 완료했다. 원래 백테스트 전략·계좌 엔진은 변경하지 않았다.

기존 현재 모멘텀 출력은 이전 파일과 바이트 단위로 같았다. SHA-256은 `00384808dc9952ac253b8ab41280051d02909d9ae80f48b88d2ba91b5b380543`이다. 새 후보의 전체 신호 출력 해시는 `9513af028c48733c98dad7d8d5ba591d206cd71788be59657b31e6bfed63ff4c`다. [현재 감사](kr-current-quarter-rank-retention-current-results/current-audit.json)에 후보·원본·월별 종목군·점수·조건과 코드 해시를, [검증 기록](kr-current-quarter-rank-retention-current-results/verification.json)에 확인 범위를 보존했다. 전체 200종목 진단은 로컬 `data/kr-quarter-research/rank-retention-current/current-signals.json`에 있다.
