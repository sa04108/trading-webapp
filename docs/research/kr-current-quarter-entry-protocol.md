# 미확인 가격 이력과 조건 발생일 진입 검증

2026-09-08, 기준 커밋 `214365a`. 이전 회차는 완료된 연구·자료 정정·검증·커밋으로 진전이 있었다. 현재 목표는 아직 미달이다. 동일한 시장 역사와 후보를 이미 본 후속 조사이며 새 독립 표본을 만들었다고 주장하지 않는다.

## 가격 이력 처리

기존 회복 60일·3종목·20봉 후보의 월간 시작점 46·45·29개를 재실행한다. 각 의사결정일 이전까지 발생한 마지막 미확인 기업행위 이후의 실제 일봉만 전략에 제공한다. 미래 사건은 현재 이력을 바꾸지 않는다. 전략이 요구하는 일봉 수가 다시 쌓이기 전에는 신규 진입 자격이 없고, 이미 보유한 포지션의 실제 가격·청산·사건 보유 실패 처리는 유지한다. 가격을 보정하거나 사건을 가로질러 주문을 가상 체결하지 않는다.

기존 날짜·배당·비용·초기자금·달력 3개월·목표 청산·낙폭 중단 규칙을 그대로 쓴다. 확장 입력의 확인된 한국항공우주 거래정지일도 반영한다. 이 처리는 과거 가격 불확실성에 대한 보수적인 진단이다. 회사별 최초 공시 빈티지와 모든 권리의 총수익을 인증하는 것은 아니다.

## 월초 외의 진입 날짜

현재 고변동성 반등 조건은 코스피 20일 연율 변동성 30% 이상·20일 수익 양수·20일 이동평균 위다. 앞선 추가 가설의 25·35% 문턱도 모두 진단한다. 월초만 보는 방식에서 비교 구간이 없었던 것은 거래일 중 발생한 빠른 반등을 놓쳤을 수 있다. 성과를 보기 전에 다음 날짜 수를 확인했다.

| 문턱 | 개발 거래일 / 비중첩 | 검증 거래일 / 비중첩 | 최근 거래일 / 비중첩 |
| --- | ---: | ---: | ---: |
| 25% | 0 / 0 | 37 / 3 | 71 / 5 |
| 30% | 0 / 0 | 19 / 3 | 58 / 4 |
| 35% | 0 / 0 | 9 / 1 | 38 / 3 |

조건은 시작일 종가로 판단하고 주문은 뒤의 실제 거래일에 체결한다. 모든 적격 거래일의 3개월 창을 보존한다. 최근 시작점이라 전체 만기가 아직 오지 않은 창은 성과 전에 제외한다. 비중첩 표본은 첫 적격일 진입 후 달력상 3개월이 지난 다음 첫 적격일로 정한다. 잦은 시작점이나 겹치는 표본을 독립 사건 수로 세지 않는다.

회복 60일 기본, 40·80일 인접값, 기존 모멘텀 20일·5종목 대조군의 네 설정을 고정한다. 25% 이상인 전체 날짜 108개를 모두 실행하고 30·35% 하위 집합을 집계한다. 설정별 최고 문턱을 골라 발표하지 않는다. 이 단계는 새 파라미터 탐색이 아니라 이미 고정한 설정의 진입일·자료 처리 검증이다.

기본 회복 후보가 30% 조건의 검증·최근 양쪽에서 성공 과반·중앙값 10% 이상이면, 같은 날짜에 편도 슬리피지 10·20bp와 기본 5bp의 시드 205·206을 추가 점검한다. 그렇지 않으면 조건부 성공을 확정하지 않는다. 비중첩 결과·인접 문턱·파라미터·미청산·기업행위·최악 손실을 같이 공개한다. 표본 수 자체가 작다는 제한은 이 기준을 통과해도 사라지지 않는다.

전체 기간 성과의 약점과 이전 채택 실패 기록을 보존한다. 조건부 진입 조사로 비활성 시장까지 10%가 나오는 전략이라고 목표를 바꾸지 않으며, 지금의 조건과 데이터 범위가 지지하는 내용만 판단한다. 운영 등록·실계좌 주문은 포함하지 않는다.


## 연속 회복 확인을 기다리는 추가 가설

기본 30% 조건의 전체 날짜 결과를 본 뒤 추가하는 가설이다. 모든 날짜 계좌는 검증 11/19·최근 36/58이지만 최초 적격일을 택한 비중첩 계좌는 각각 0/3·0/4였다. 최초 회복 신호의 일시적인 반등을 걸러야 한다는 가설을 조사한다. 현재 조건도 9월 7일과 8일 두 거래일 연속 충족이고 그 전 3거래일은 이탈했다.

기본 대기는 5거래일 연속 확인으로 정하고 인접 3·10일을 모두 공개한다. 회복 60일·3종목·20봉, 변동성 문턱 30%, 다른 규칙은 유지한다. 처음 적격한 날부터 시작한 원래 3개월 계좌 안에서 기다린다. 실제 활성화일로 만기를 미루지 않고 끝까지 확인되지 않으면 현금 대기 실패로 센다. 활성화 첫날은 목표를 정하고 이후 실제 종가·시가의 두 단계 매매를 따른다. 그 뒤에는 원래 회전 일정과 청산 규칙을 사용한다. 확인 대기는 최초 진입에만 적용한다.

동일하게 고정된 검증 19개·최근 58개 시작점을 세 설정 모두 실행한다. 기본 후보의 비용·시드 진단과 분리해 집계하며, 이 추가 가설을 독립적인 블라인드 검증으로 부르지 않는다. 수익을 본 뒤 대기 일수나 시작일을 바꾸지 않는다.
