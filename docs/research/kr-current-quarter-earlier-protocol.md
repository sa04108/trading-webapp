# 2011년 변동성 국면의 추가 자료와 고정 후보

2026-09-08, 기준 커밋 `bc99bbd`. 2015년 이후 같은 시장 이력을 반복해서 본 한계 때문에 아직 평가하지 않은 이전 국면을 추가한다. 미래에 확보한 새로운 시장 관측은 아니며 과거 역사에 대한 추가 평가다. 2011년의 성과를 보고 후보를 다시 조정하지 않는다.

기존 Npay 코스피 원문의 조건만 읽어 2011~2014년을 검사했다. 20일 연율 변동성 30% 이상·20일 수익 양수·20일 이동평균 위이고 달력 3개월 만기가 완성되는 시작일은 18개, 첫 적격일 기반 비중첩은 2011-09-07·2011-12-07 두 개다. 25%는 24개·비중첩 두 개, 35%는 11개·비중첩 한 개다. 종목 수익을 읽기 전에 날짜를 정했다. 지수 원문 SHA256과 모든 날짜는 로컬 `earlier/date-audit.json`에 보존한다.

후보는 회복 60일·3종목·손절 8% 기본, 같은 규칙의 손절 12% 관찰 후보, 회복 20일·3종목·손절 8% 대조군으로 고정한다. 목표 연율 변동성 30%, 20봉 회전, 시장·유가·환율·VIX·금리 조건, 계좌 고점 대비 10% 낙폭 중단·원래 달력 3개월·실제 비용 후 10% 판정을 유지한다. 연속 확인 대기는 없다. 30% 전체 18개를 우선 평가하고 25·35%도 날짜 선택 영향을 따로 공개한다. 이 두 국면을 충분한 통계 표본으로 부르지 않는다.

KRX 공식 제공 범위는 2010년 이후다. 앱 DB의 2015년 이전 일봉은 0행이었다. 기존 승인 환경에서 2011-01-03·2011-09-07의 KOSPI·KOSDAQ 일봉·종목 기본정보 8회 조회가 모두 비어 있지 않은 원문을 반환했다. [KRX 공식 제공 범위](https://openapi.krx.co.kr/contents/OPP/INFO/service/OPPINFO004.cmd), [유가증권 일별 API](https://openapi.krx.co.kr/contents/OPP/USES/service/OPPUSES002_S2.cmd?BO_ID=JvJFzlAENzZlPBDNGAWC)

추가 수집은 2011-01-03부터 25% 조건의 마지막 만기까지의 실제 지수 거래일로 제한한다. 각 날짜의 두 시장 일봉과 기본정보를 받아 당시 보통주 여부·시가총액·거래대금·거래 가능 상태를 구성한다. 시가총액 200종목을 전일 정보와 20일 평균 실제 거래대금 10억원으로 매월 선정한다. 현재 생존 종목을 과거에 적용하지 않는다. 이미 보존한 8개 응답은 재사용하며 중복 API 호출을 피한다.

실제 OHLC·거래량·종목 이력·가격단위 연속성을 먼저 대조한다. 확인되지 않은 기업행위 이후 실제 일봉만 신호에 사용하고 사건 보유 계좌는 성공으로 세지 않는다. 의심 가격을 유리한 방향으로 보정하거나 거래 가능 봉을 만들지 않는다. 원자료가 불완전하면 그 계좌를 완료된 검증으로 표시하지 않는다. 과거 거시자료에도 동일한 관측 지연을 적용하며, 새로운 자료 빈티지의 개정 가능성을 기록한다.

인증키는 원격 앱 환경 안에서만 사용하고 사용량 원장은 읽기 전용으로 확인한다. 호출·원문·실패는 연구 파일에 보존한다. 운영 데이터 수집 원장이나 서비스는 변경하지 않는다. 이 수집기는 다른 동시 수집기의 모든 호출을 전역 예약하지 않으므로 각 API의 한도 중단 기록과 충분한 여유를 확인한다. 원문은 Git에 넣지 않으며 공개 푸시 승인 대기를 우회하지 않는다.
