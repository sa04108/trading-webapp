# 보유 순위 완충 모멘텀의 고정 비교

2026-09-09, 기준 커밋 `ed86140`. 인접 회전 15봉에서 2024-09-02 시작 계좌의 이익이 손실로 바뀐 결과를 본 뒤 만든 후속 가설이다. 기존 검증·최근 자료를 다시 사용하는 적응적 탐색이며 미사용 평가가 아니다. 새 전략의 성과를 보기 전에 아래 규칙과 전체 실행을 고정한다.

연구 전략 `rank-retention-momentum`은 기존 20일·skip 0·양수 모멘텀 순위와 2단계 동일가중 교체를 사용한다. 회전일에 보유 종목 중 현재 적격 순위 10위 이내인 종목을 먼저 유지하고 남은 슬롯만 순위가 높은 종목으로 채워 최대 5개를 보유한다. 보유 종목도 종목군 탈락·양수 모멘텀 미달·이력 부족이면 유지하지 않는다. 과대 비중 조정과 다음 봉의 부족 수량 매수는 기존 공유 함수를 사용한다. 최초 현금 상태에서는 기존 상위 5개와 같으며 이미 청산한 종목의 과거 보유 상태를 기억하지 않는다.

순위 유지 경계는 10위 하나만 시험한다. 회전 20봉을 기본으로 두고 15·25봉도 함께 고정해 비교한다. `rank-retention-experiments.json`의 6개 실행은 검증 19개·최근 58개씩 총 231개 새 계좌이며 같은 주기의 기존 재개 계좌 231개와 대조한다. 기본 대조군 20봉은 기존 재개 결과, 15·25봉은 직전 인접 파라미터 결과다. 좋은 주기만 선택하지 않으며 세 주기·두 단계 모두 전체 목표 성공 과반·수익 중앙값 10% 이상·첫 적격일 비중첩 성공 과반이어야 이번 진행 기준을 통과한다.

원래 입력·시작일·만기·거래일 일정은 유지한다. 초기 1억원, 평가 목표 +10.5%·실제 목표 +10%, 최고점 대비 −15% 중단, 목표 미달 전량 청산 뒤 정상 일정 재개, 이력 제한, 시드 204, 일정 이동 0, 편도 슬리피지 5bp·수수료 1.5bp·날짜별 매도세·직전 거래량 1% 한도를 고정한다. 실제 낙폭이 중단 기준을 넘을 수 있다는 기존 한계는 유지한다.

구현 검증은 유지 경계·신규 후보 채움·부적격 보유 제외·매도 후 매수 단계·보유 수 상한, 유지 경계를 보유 수와 같게 했을 때 기존 전략과의 체결 결과 일치로 한다. 기본 전략의 이전 원본 계좌도 재현해 전략 분기 추가가 기본 동작을 바꾸지 않았는지 확인한다. 운영 레지스트리에는 등록하지 않는다.

성과와 함께 모든 같은 날짜 비교, 비중첩 계좌, 체결 수·비용 차이, 낙폭·미청산·기업행위 불확실성을 보존한다. 이번 진행 기준에 실패하면 경계 숫자를 다시 골라 이 비교를 통과한 것으로 바꾸지 않는다. 통과하더라도 기존 과거 구간 실패·현재 유사 국면 표본 부족은 사라지지 않으며 비용·시드·환경 등 추가 확인 전 실전 채택으로 표시하지 않는다. 현재 자료 기준은 2026-09-08 종가이며 실주문은 보내지 않는다.
