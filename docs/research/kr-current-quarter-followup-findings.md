# 2026-09-08 후속 탐색: EMA와 분기 이익 가속

**실전 투입을 뒷받침하는 후보는 추가로 찾지 못했다.** 기존 EMA 6개 설정과 분기 이익 가속 9개 설정을 개발하고, 결과 확인 전에 고정한 인접 후보를 후속 평가했다. 이번 회차는 31개 실험·완료된 3개월 계좌 1,282개다. [이전 회차](kr-current-quarter-findings.md)의 4,809개와 합하면 6,091개지만 중첩 시작점·같은 시장·비슷한 전략을 공유하므로 독립 증거의 수가 아니다. 개발 설정은 누적 84개다.

목표는 여전히 달성하지 못했다. 실적 원문과 새로운 평가 경로를 확보한 진전은 보존하지만, 테스트 통과나 탐색량 증가를 금융 목표 달성으로 바꾸지 않는다. 앞선 회복 순환·연간 실적 모델의 결과도 그대로 유지한다.

## 추가 데이터와 시간 기준

DART 공식 다중회사 주요계정 API를 92회 조회해 과거 상위 50종목 합집합 123개 회사의 원응답을 보존했다. 사전 의미 확인 조회 4회를 포함하면 96회다. 앱의 기존 인증 환경에서 API를 호출했으며 인증키를 연구 파일에 복사하지 않았다. 일별 사용 원장은 읽기 전용으로 확인했고 수집기의 자체 호출 수와 함께 한도를 확인했다. [DART 응답 필드·요청 안내](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS003&apiId=2019017)

연도·보고서·회사·원화·달력 분기·연결/별도 기준을 확인한 뒤 누적 이익을 차분했다. 2·3분기는 계산된 차분과 당기 분기액이 100만원 이내에서 일치해야 한다. 4분기는 연간 영업이익에서 9개월 누적 이익을 차감한다. 필요한 두 보고서 중 늦은 접수일의 다음 날부터 신호에 노출한다. 과거 정정본을 최초 공시일로 소급하지 않는다.

결과는 121개 종목의 8,282개 분기 관측이다. 연결과 별도는 별개 관측으로 센다. 제외된 399개는 같은 기준의 직전 누적액 누락 255개, 당기액·누적액 누락 11개, 당기액과 차분의 큰 불일치 133개다. 2015년 분기·반기 요청에는 자료 없음 응답이 왔으므로 사업보고서만으로 2015년 4분기 이익을 만들지 않았다. API의 연도 지원 범위와 실제 분기 존재 여부를 구분했다.

기존 이익 가속 전략은 같은 회계기준의 연속 8개 분기 영업이익이 필요하다. 처음 충족한 월간 시작점은 2018년 4월이다. 개발 46개 시작점 중 19개에 한 종목 이상의 자료가 있고, 13개에서 종목군의 절반 이상이 충족한다. 검증은 45개 중 37개, 최근 확인은 29개 모두 절반 이상이 충족한다. 개발 초기 현금 대기 때문에 전체 중앙값이 0%인 결과를 전략의 안정성으로 해석하지 않는다.

이번 수집 역시 최신 API 빈티지다. 과거 최초 발표값의 완전한 복원이나 동일 회계기준 안의 모든 회계정책 변경 검증을 뜻하지 않는다. 자료 누락은 신호와 선택 종목을 바꿀 수 있다.

## 결과

현금 1억원, 레버리지 없음, 비용 후 청산 수익 10% 이상이라는 이전 조건을 유지했다. 계좌 평가이익 +10.5%에서 청산 신호, 고점 대비 10% 낙폭에서 중단 신호를 낸다. 다음 실제 거래일의 체결·거래량 제한 때문에 실제 수익과 낙폭은 문턱을 넘을 수 있다. 상세 설정은 [성과 계산 전 고정한 규칙](kr-current-quarter-followup-protocol.md), 전체 결과는 [후속 실험 표](kr-current-quarter-followup-results/all-summaries.csv)에 있다.

기간이 겹치지 않는 최근 시작점은 각 9개다. 기본 EMA와 기본 이익 가속 모두 목표 달성은 1/9다. 자료를 갖춘 종목이 절반 이상인 검증 시작점 37개만 보아도 기본 이익 가속은 10/37 성공·중앙값 −5.21%다. 초기 공시 부족만으로 약한 성과를 설명하기 어렵다. 개발의 자료 충족 시작점 13개에서도 기본 이익 가속은 0/13·중앙값 −2.63%다.

수익 분포는 원 계좌 계산값이며, 확인되지 않은 기업행위가 걸린 계좌의 수익까지 인증한다는 뜻이 아니다. 이런 계좌는 목표 성공에서 제외했다. 기본 EMA는 검증 1개·확인 2개, 기본 이익 가속은 검증 1개·확인 1개가 해당한다. `uncertainActionAccounts`와 개별 계좌의 `affectedActions`에 표시했다. 예를 들어 기본 이익 가속의 2026년 5월 계좌 수익은 +15.82%지만 보유 중 셀트리온의 미확인 기업행위가 걸려 목표 성공으로 세지 않았다.

## 현재와 유사한 환경

앞서 고정한 수출 전년비 +10% 초과, 코스피 20일 양수·60일 음수, 두 조건의 교집합을 재사용했다. 수출 관측의 공개 지연 가정과 현재 빈티지 한계도 그대로다. 현재 거시 환경의 출처와 해석은 [이전 보고서](kr-current-quarter-findings.md)에 있다.

두 기본 후보 모두 수출 증가·조정 후 반등의 교집합에서 개발 0/2, 검증 0/2였고 최근 확인에는 비교 시작점이 없다. 반등 조건만 사용해도 기본 EMA·이익 가속은 각각 검증 1/5, 확인 0/2다. 더 넓은 수출 증가 조건에서 기본 이익 가속은 최근 4/9지만 검증은 0/17이다. 최근 표본만으로 현재 투입의 근거를 만들 수 없다.

이전 조건별 규칙의 각 단계 독립 표본 10개 문턱은 현재 월 첫날 평가 방식에서 최근 확인 시작점 자체가 최대 9개라 충족할 수 없다. 이는 보수적인 연구 규칙의 설계 한계이며 사용자 요구가 아니다. 다만 이번 결과는 그 문턱을 적용하기 전에도 검증 수익·목표 빈도가 약하다. 표본 규칙을 사후 완화해 통과시킬 후보는 없다.

## 오늘 신호와 재현

현재 50종목 중 45종목이 분기 자료 요건을 충족했다. 기본 이익 가속의 오늘 목표는 SK·SK스퀘어·SK하이닉스·삼성전자·LS ELECTRIC 각 20%다. 동일가중 5종목이어도 반도체 관련 노출이 집중된다. 아직 목표 선정 단계이며 실제 매수 체결을 뜻하지 않는다. 현재 종가 뒤의 미래 봉·체결을 생성하지 않았다.

기존 `earnings-acceleration-rank`의 이익 가속·가격 모멘텀 순위와 두 단계 회전을 그대로 사용하고, 검증한 분기 스냅샷을 연구 어댑터로 연결했다. 운영 전략 등록이나 운영 엔진 변경은 없다. 이번 결과는 채택을 뒷받침하지 않으므로 현재 종목 목록을 실전 추천으로 승격하지 않는다.

원문과 모든 계좌는 `data/kr-quarter-research/followup/`, 집계·해시는 `followup/evidence/`에 보존했다. 재현 명령은 [스크립트 안내](../../scripts/quarter-research/README.md), 공개할 결과 해시는 [후속 증거 목록](kr-current-quarter-followup-results/evidence-manifest.json)에 있다. 이전 회차 결과 파일과 집계 목록은 덮어쓰지 않았다.

검증: 관련 TypeScript 6개 파일·51개 사례, Python 10개 사례, 연구 TypeScript ESLint, 서버 범위 타입 검사를 통과했다. 분기 정규화 재실행은 원본과 바이트 단위로 같고, 기존 모멘텀의 첫 확인 계좌를 재실행해 전체 JSON과 해시가 같음을 확인했다. 신규 1,282개 계좌의 입력 해시·개별 결과·요약도 대조했다. 기본 성과를 통과한 후보가 없어 추가 시드·비용 스트레스 평가로 승격하지 않았다. 전체 저장소 테스트는 실행하지 않았다.
