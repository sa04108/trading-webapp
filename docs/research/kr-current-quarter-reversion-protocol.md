# 기존 RSI 평균회귀 전략의 추가 평가

2026-09-08. 모멘텀·돌파·회복·실적 결합 결과를 본 뒤, 높은 단기 변동성에서 반등을 짧게 거래하는 기존 `rsi-reversion`을 추가한다. 뒤의 기간은 다른 가설에서 이미 살펴봤으므로 새 블라인드 검증으로 표현하지 않는다.

개별주에 RSI 기간 2·5·14봉 × 진입 RSI 10·30의 여섯 조합을 평가한다. 청산 RSI 60, ATR 14봉, 손절 3 ATR, 최대 보유 10봉, 거래당 위험 예산 1%, 최대 보유 5종목, 상관 계산 60봉·역상관 문턱 0.5, 종목군 재검토 5봉으로 고정한다. 기존 알고리즘의 시드에 따른 동시 진입 선택을 그대로 사용한다. 거래당 위험 예산은 비중 상한이 아니며 현금 제한으로 주문이 줄 수 있으므로 실제 비중과 시드 민감도를 확인해야 한다.

개발 구간의 모든 결과를 저장한다. 기본 진단은 RSI 5·진입 30, 인접 진단은 RSI 2·진입 30과 RSI 14·진입 30으로 고정한다. 전체 계좌의 목표·낙폭·만기 조건은 기존 연구 규칙과 같다. 현재 조건 집합은 `kr-current-quarter-context-protocol.md`를 그대로 따른다.
