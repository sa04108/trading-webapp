# 거래대금 중심 종목군 추가 탐색

시가총액 상위 50종목의 기존 84개와 신규 눌림목 12개 개발 조합에서 적격 후보가 없었다. 대형주로 제한한 표본에서 시장 전체 가능성까지 부정하지 않도록 아래 추가 탐색을 한다. 이 단계에서도 2020년 이후의 새 조합 성과는 열기 전에 규칙을 고정한다. 이전 단계 EMA 하나의 후속 실패는 이미 확인했다.

- 당시 보통주 중 직전 20거래일 평균 거래대금 10억원 이상을 유지하고, 시가총액 대신 같은 평균 거래대금 상위 100개를 월초 선정한다. 다음 5거래일 재평가일에 반영한다.
- 가격 데이터만 필요한 전고점 돌파·횡단면 모멘텀·새 단기 추세 눌림목의 세 가족만 실행한다. 다른 세 재무 가족의 불완전 공시 이력은 이 단계에서 해결됐다고 가정하지 않는다.
- 돌파와 눌림목은 앞 단계의 세 파라미터를 그대로 쓴다. 횡단면 모멘텀은 단기 목적에 맞춰 형성 기간 20·40·60봉, 최근 제외 0봉, 상위 5종목으로 탐색하며 40봉을 기본값으로 둔다.
- 나머지 국면·개발/검증 경계·비용·20봉 공통 상한·5봉 눌림목 상한·벤치마크 정의·선택 기준은 그대로다. 합계 36개 조합이다.
- 적격 후보가 없으면 그 사실을 기록하고 새 전략의 기본값 하나를 진단용으로 후속 구간에 고정한다. 후속 결과를 보고 이 단계의 다른 파라미터를 골라 검증에 통과했다고 표현하지 않는다.

앞 단계의 실패와 수정 전 일정에서의 실행도 탐색 이력에 포함한다. 이 확장은 사전에 완전히 독립인 전략 검증이 아니라 개발 구간에서 수행한 추가 탐색이다.
