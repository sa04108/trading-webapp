# 보유 순위 완충 후보의 실행·비용·환경 진단 결과

2026-09-09 작성, 가격·거시 기준은 2026-09-08 종가다. 기준 커밋 `2141fe9`에서 [사전 규칙](kr-current-quarter-rank-retention-diagnostics-protocol.md)을 고정하고 20개 실행·717개 새 계좌를 완료했다. 최초 후보의 기본 77개를 재사용하고, 동일 조건의 기존 재개 정책 794개와 대조했다. 다른 설정에서 반복한 같은 날짜는 독립 시장 관측으로 더하지 않는다.

**실행 시드·선정일 이동·비용과 검증·최근 구간의 25·30·35% 변동성 문턱은 진행 기준을 통과했다.** 개발 무조건 월간과 2011년은 통과하지 못했다. 새 717개 중 667개는 기존과 매매 결과가 같았고, 목표 성공 전환은 개발 구간의 1개였다. 현재 유사 환경의 표본 부족도 그대로여서 기본 20봉을 후속 연구 후보로 유지한다. 실전 투입은 아직 확정하지 않았다.

## 고정 후보와 실행 변화

20일 수익률·skip 0·양수 모멘텀으로 순위를 매기고 최대 5종목을 보유한다. 실제 보유 종목이 적격 순위 10위 안이면 유지하고 빈 자리만 높은 순위로 채운다. 종목군·이력 조건과 동일가중 매도·다음 봉 매수 단계는 유지한다.

연구 가정은 초기 1억원, 평가 목표 +10.5%·실제 비용 후 목표 +10%, 원래 최고점 대비 −15% 중단, 달력 3개월 만기다. 목표 미달 전량 청산 뒤 원래 일정의 매매를 재개하며 최고점·자금·만기를 초기화하지 않는다. 수수료 1.5bp·날짜별 매도세·직전 거래량 1% 한도는 고정했다. 기본 진입 조건은 코스피 20일 연율 변동성 30% 이상·20일 수익 양수·20일 평균 위다.

비용은 목표 청산 날짜와 재개 경로도 바꿀 수 있어 중앙값이 비용에 따라 단조 감소하지 않는다. 20bp에서 검증 중앙값이 높다고 더 높은 비용을 좋은 실행 조건으로 해석하지 않는다.

25%에만 추가되는 검증 18개·최근 13개를 기본 30% 계좌와 합쳤고, 35%는 고정 날짜의 부분집합으로 집계했다. 25% 추가 검증 18개만 따로 보면 목표 성공 9/18·비중첩 1/2로 과반에 못 미친다. 이를 제외하지 않고 합친 조건과 함께 보존한다.

## 과거 부진과 수익 변화

조건 없이 매월 시작한 개발 46개는 장세를 구분하지 않는 별도 진단이다. 성공은 기존 16/46에서 17/46으로 늘었지만 수익 중앙값은 −0.36%에서 **−0.42%**로 낮아졌다. 비중첩 성공 6/14, 최악 수익 −18.93%, 최대 낙폭 −20.67%, 미청산 2개다. 이 무조건 월간 결과를 현재 조건부 진입 정책의 성과로 바꾸어 표시하지 않는다.

2011년은 같은 고변동·단기 반등 조건의 다른 역사 환경이다. 25% 문턱의 성공 5/24·비중첩 0/2는 기존과 같았고, 중앙값은 −4.64%에서 **−5.92%**로 악화됐다. 30%는 4/18·비중첩 0/2·중앙값 −10.78%, 35%는 2/11·비중첩 0/1·중앙값 −12.78%다. 보유 유지 규칙으로 과거 실패가 해결됐다고 표시하지 않는다.

전체 새 계좌의 수익 개선은 34개·감소는 16개, 매매 결과가 같은 계좌는 667개다. 목표 실패→성공은 1개·성공→실패는 0개다. 체결은 42건, 수수료·매도세·모형 슬리피지 합계는 7,574,541원 감소했다. 여러 반복 계좌의 합계이며 한 실계좌의 절감액 예측치가 아니다.

- 개발 2019-04-01 시작은 −7.91%에서 +10.89%로 바뀐 유일한 목표 성공 전환이다.
- 2011-12-05 시작은 비용이 약 102만원 줄었어도 −6.22%에서 −13.07%로 악화됐다.
- 시드 205·2026-04-21 시작은 +22.02%에서 +14.43%로 낮아졌다.

개선과 악화를 모두 [같은 날짜 전체 비교](kr-current-quarter-rank-retention-diagnostics-results/paired-accounts.json)에 보존했다. 앞선 가설의 계기가 된 2024년 9월·15봉 계좌는 이번 기본 20봉 후속 비교의 새로운 개선 사례로 다시 세지 않는다.

## 잔량과 기업행위 불확실성

새 717개 중 미청산 3개는 기존과 매매 결과가 같고 모두 목표 실패로 유지한다. 실제 직전 거래 봉의 1% 한도와 당일 거래량을 대조했다. 마지막 실제 매도 구간에는 단위 변경 팩트가 없었고 아래 체결량이 한도와 일치했다. 남은 평가액을 실현 현금으로 취급하지 않는다.

## 현재 환경 재확인과 검증 범위

한국은행은 8월 27일 기준금리를 2.75%에서 3.00%로 인상했고 중동 긴장과 에너지 가격을 불확실성 요인으로 설명했다. [한국은행 발표](https://www.bok.or.kr/portal/bbs/P0000559/view.do?menuNo=200690&nttId=11064191) 8월 소비자물가는 전년 대비 3.1%, 식료품·에너지 제외 지수는 3.4% 상승했다. 통신요금 할인 기저효과를 제거한 전체 물가 상승률은 약 2.5%라는 설명도 함께 확인했다. [8월 물가 발표](https://www.korea.kr/news/policyNewsView.do?newsId=156777515)

현재는 금리 인상과 물가·에너지 불확실성을 고려해야 하는 환경으로 판단한다. 이는 공식 자료에 근거한 상황 해석이며 수익 예측치가 아니다. 확인 당시 EIA 페이지의 최신 전망은 8월 11일 발표본이고 다음 발표는 9월 9일로 표시돼 있었다. 아직 게시되지 않은 9월 전망을 사용하지 않았다. [EIA 단기 에너지 전망](https://www.eia.gov/outlooks/STEO/)

현재 주가 입력은 앞서 보존한 Npay의 9월 8일 종가를 유지한다. KRX의 해당 일자 원문을 추가 대조하려던 조회는 운영 인증 환경 접근이 자동 승인 검토에서 거절되어 실행하지 못했다. 별도 승인을 요청했으며 대조 완료로 표시하지 않는다. 이 추가 조회는 이번 과거 계좌 입력·결과를 바꾸지 않는다.

새 후보의 현재 유사 조건을 다시 집계해도, 20일 반등·60일 하락의 비중첩 표본은 검증·최근 각 1개다. 수출 성장 조건까지 합치면 각 0개다. 원래 현재 환경 판정에 필요한 단계별 비중첩 10개 기준을 충족하지 못한다. [조건 표본](kr-current-quarter-rank-retention-diagnostics-results/context-summary.json)에 최신 수정 수출 자료·관측 월초+90일 공개 가정과 당시 발표본 미인증 한계를 함께 기록했다.

거래 TypeScript와 테스트는 `2141fe9` 그대로다. 해당 커밋의 7개 파일·50개 테스트, ESLint·서버 타입 검사·기본 계좌 바이트 재현이 적용되며 이번에 다시 거래 테스트를 실행한 것으로 표시하지 않는다. 새 Python 집계기 컴파일·전체 집계와 새·기존 원본 1,588개 및 요약 44개의 1,632개 해시·고정 설정·현금·비용·위험·최초 매수·조건 날짜를 대조했다. [검증 기록](kr-current-quarter-rank-retention-diagnostics-results/verification.json)에 적용 범위를 보존했다.

선정 기간·보유 수·유지 경계의 새 후보 민감도 확인은 아직 남았다. 이번 통과는 현재 환경에 충분한 근거가 있다는 결론이나 실전 투입 승인을 대신하지 않는다. 실주문은 보내지 않았다.
