# 현재 환경과 과거 시작점 비교 규칙

2026-09-08. 이전 후보들의 구간별 전체 결과를 확인한 뒤 작성했다. 아래 조건별 성과는 아직 계산하지 않았다. 조건별 결과가 좋은 조합으로 임계값을 다시 바꾸지 않는다.

현재의 강한 수출 증가와 조정 후 반등이 전체 기간보다 유리한 진입 환경인지 비교한다. OECD 한국 월별 수출액(FRED `XTEXVA01KRM667N`)의 전년 동월 증가율을 사용한다. 개정 이력이 없는 최신 빈티지이므로 인증된 과거 발표 시점 자료는 아니다. 월초로 표시된 관측일에 90일을 더한 뒤부터만 알고 있었다고 가정한다. 이 보수적 지연도 개정 문제를 해결하지는 못한다. IMF `VALEXPKRM052N`과 최근 값의 단위 차이를 대조한다.

성과를 비교할 시작점 집합은 전체, 수출 전년비 10% 초과, 코스피 20일 수익 양수이면서 60일 수익 음수, 두 조건의 교집합 네 가지다. 마지막 두 조건은 현재의 조정 후 반등을 표현한다. 현재 변동성이 과거보다 높은지도 별도로 표시하되 성과에 맞춰 변동성 문턱을 조절하지 않는다. 월별 관측의 중첩을 제거한 표본 수와 결과를 반드시 병기한다.

모든 후보와 모든 조건의 실패도 저장한다. 표본이 적은 조건에서 나온 높은 빈도는 검증 통과로 보지 않는다. 현재 상황에 해당하는 표본에서 검증·확인 각 최소 10개의 중첩되지 않는 관측이 없는 경우 통계적 근거 부족으로 표시한다. 현재 국제 정세와 동일한 과거가 반복된다고 가정하지 않는다.

실적 결합 전략의 후속 진단은 기본값 `quality-60-15`와 단일 축 인접값 `quality-20-15`, `quality-120-15`, `quality-60-0`, `quality-60-30`으로 고정했다. 개발 구간에서 채택 기준을 통과한 후보는 없다.
