# 후속 확인 후보 고정

2026-09-08 KST, 개발 54개 설정 × 46개 시작 창을 모두 확인한 뒤, 검증·최종 구간을 실행하기 전에 고정했다. 목표 기준을 통과한 후보는 없으며 아래는 실패의 시기별 차이를 확인할 진단 후보다.

- 주식: 개발 목표 빈도가 가장 높았던 20봉·5종목·20거래일 회전과 20봉·3종목, 60봉·5종목 이웃값. 같은 20봉·5종목의 5거래일 회전도 비교한다. 새 전략은 월간 회전의 60봉·3종목 기본값과 40·80봉 이웃값을 고정한다.
- ETF: 개발 목표 빈도가 높았던 120봉·3종목·5거래일 회전과 20·60봉 이웃값. 새 전략은 60봉·3종목의 5거래일 회전과, 40·60·80봉·3종목의 20거래일 회전을 고정한다.

각 일곱 후보를 검증 2020–2023 및 최종 확인 2024–최신 완결 3개월 창에 같은 파라미터로 실행한다. 미래 구간에서 좋아진 값으로 교체하지 않는다. 현재 주식 종목군은 별도 수집하며 과거 종목군을 대체하지 않는다.
