# 2026-09-08 진입일·가격 이력 후속 검증

**회복 60일·3종목 후보의 조건부 계좌 집계 성과는 좋아 보이지만, 시작일 의존성이 커서 실전 채택을 보류한다.** 코스피 고변동성 반등일에 시작한 최근 58개 계좌 중 36개가 비용 후 10%를 달성했고 중앙값은 +11.32%였다. 그러나 첫 적격일부터 시작해 서로 겹치지 않게 운용한 4개 계좌는 모두 실패했다. 5일 확인 대기도 이 4개의 실패를 해결하지 못했다. 현재부터 3개월에 10%를 목표로 투입할 전략을 찾는 목표는 아직 충족하지 못했다.

이번 회차는 가격 이력 진단 120개, 기존 네 설정의 모든 조건 발생일 432개, 비용·시드 진단 308개, 추가 확인 대기 가설 231개로 총 25개 실험·1,091개 완료 계좌다. 같은 시장 이력을 재사용한 후속 조사이며 독립적인 새 표본이 아니다. 성공은 원래 시작일부터 달력 3개월 안에 실제 청산하고 비용 후 10% 이상을 남기는 경우다. 현금 대기·미청산·보유 중 미확인 기업행위는 성공으로 세지 않았다. ## 미확인 가격 이력의 영향

각 의사결정일 이전에 발생한 마지막 미확인 기업행위 이후의 실제 일봉만 전략에 제공했다. 필요한 126개 일봉이 다시 쌓이기 전에는 신규 매수 자격이 없다. 미래 사건은 현재 이력을 바꾸지 않으며, 이미 보유한 포지션의 실제 가격·청산 경로는 유지한다. 가격을 임의로 연결하거나 보유 사건의 실패 판정을 없애지 않았다.

| 회복 60일·3종목, 월 첫 거래일 시작 | 종전 성공 | 처리 후 성공 | 처리 후 중앙값 | 처리 후 비중첩 성공 |
| --- | ---: | ---: | ---: | ---: |
| 개발 2016~2019 | 5/46 | 7/46 | −0.73% | 3/14 |
| 검증 2020~2023 | 10/45 | 12/45 | +0.98% | 3/13 |
| 최근 2024년 이후 | 16/29 | 15/29 | +10.37% | 4/9 |

최근 비중첩 중앙값은 종전 +10.37%에서 +3.69%로 낮아졌다. 최근 2025-03-04 계좌가 +11.63% 성공에서 +2.08% 실패로 바뀌었다. 개발 10개·검증 12개·최근 6개의 수익이 달라졌으며, 모두 [변경 전후 대조](kr-current-quarter-entry-results/monthly-comparison.json)에 보존했다. 이 결과가 이전 보고서의 회복 후보 월간 평가를 보완한다. 기업행위 최초 공시 빈티지·모든 권리의 총수익을 인증한 결과는 아니다.

## 모든 조건 발생일과 중첩 영향

고정 조건은 코스피 20일 연율 변동성 30% 이상·20일 수익 양수·20일 이동평균 위다. 조건을 판단하는 시작일 종가 이후에 주문한다. 25% 이상인 모든 완성된 창을 먼저 실행하고 30·35% 하위 집합을 함께 공개했다. 개발에는 적격일이 없고, 검증에는 30% 조건 19개, 최근에는 58개가 있다. 자료 마지막 날은 2026-08-14여서 그 안에 만기가 완성되지 않는 시작일을 성과를 보기 전에 제외했다.

## 연속 확인을 기다린 추가 가설

위의 비중첩 실패를 확인한 뒤, 최초 매수 전에 회복 조건을 5거래일 연속 확인하는 가설을 추가했다. 인접 3·10일도 실행했다. 이는 사후 가설이며 같은 역사를 다시 본 실험이다. 대기는 원래 계좌의 달력 3개월 안에 포함했고, 활성화 첫날에 순위를 정하되 이후 회전 일정도 원래 계좌에 고정했다. 조건 확인 후 실제 매매가 가능한지는 주문·체결 기록으로 구분했다.

| 최초 확인 대기 | 검증 성공 / 중앙값 | 최근 성공 / 중앙값 | 검증 비중첩 | 최근 비중첩 |
| --- | ---: | ---: | ---: | ---: |
| 없음 | 11/19 / +10.76% | 36/58 / +11.32% | 0/3 | 0/4 |
| 3거래일 | 11/19 / +11.65% | 38/58 / +11.99% | 0/3 | 0/4 |
| 5거래일 | 12/19 / +11.14% | 37/58 / +11.80% | 1/3 | 0/4 |
| 10거래일 | 0/19 / 0.00% | 29/58 / +9.81% | 0/3 | 0/4 |

5일 대기의 최근 비중첩 계좌는 각각 0.00%, +1.34%, −2.62%, −8.04%다. 첫 계좌는 확인 조건이 성립하지 않아 끝까지 현금으로 남았다. 10일 대기의 검증 19개도 모두 무거래다. 이 현금 대기를 목표 달성이나 새로운 3개월 기회로 바꾸지 않았다.

기본 후보의 편도 슬리피지를 5→10→20bp로 올려도 검증 11/19·최근 36/58 성공 수는 같았다. 중앙값은 각각 검증 +10.76/+10.73/+10.55%, 최근 +11.32/+11.30/+11.32%였다. 비용 때문에 청산 시점과 이후 경로가 바뀌므로 수익은 단조롭게 줄지 않는다. 시드 205·206도 성공 수는 같지만 시드 206의 최근 손실 계좌는 7개에서 6개로 바뀌었다. 모든 진단에서 비중첩 성공은 검증 0/3·최근 0/4다.

## 지금의 해석과 다음 조사

9월 8일 종가에서 코스피 변동성은 45.45%, 20일 수익 +10.40%, 60일 수익 −14.39%다. 고변동성 반등 조건은 9월 7·8일 두 거래일 연속 충족했다. 따라서 5일 확인 후보의 현재 상태는 **현금 대기**다. 앞으로 3거래일 더 연속 충족할지 알 수 없고, 대기로 3개월 만기를 연장하지 않는다. [현재 조건·입력 해시](kr-current-quarter-entry-results/current-confirmation-state.json)

기존 즉시 진입 후보의 GS·S-Oil·한진칼 비중은 이전 보고서의 미채택 관찰 신호다. 확인 대기 후보의 현재 주문으로 취급하지 않는다. 금리·물가·수출·유가·국제 정세의 발표일 및 자료 한계는 [당일 거시 환경 기록](kr-current-quarter-findings.md)에 보존했다. 이 환경 해석이나 최신 일봉만으로 향후 수익을 증명할 수는 없다.

기본 후보의 실패한 비중첩 7개에는 계좌 고점 대비 낙폭 중단이 없었다. 종목별 8% 손절과 시장 회복 조건 이탈에 따른 매도가 반복됐고, 계좌는 최종적으로 만기 청산 신호를 냈다. 다음으로 조사할 원인은 이 개별 청산과 재진입 구조다. 이 7개 수익을 보고 손절 폭 하나를 골라 채택하지 않으며, 다음 가설은 별도 범위로 고정하고 인접 설정과 다른 구간을 함께 평가한다.

## 재현과 검증

운영 엔진·운영 전략 등록은 변경하지 않았다. 연구 실행기에 고정 시작일, 미확인 사건 이후 이력, 최초 확인 대기 옵션을 추가했다. 옵션 없이 재실행한 기존 2024-01-02 전체 계좌는 원본과 바이트 단위로 일치했다. 날짜 선정 옵션 3개와 날짜 감사 파일도 새 임시 경로에서 동일하게 재현됐다. 1,091개 계좌의 입력·후보·옵션·비용·시드·위험 규칙·요약을 대조하고 전체·비중첩 통계를 재계산했다.

관련 TypeScript 4개 파일·14개 사례, Python 19개 사례, 연구 ESLint와 서버 타입 검사를 통과했다. 배당 제외, 최신 거시·공시 빈티지, 미확인 기업행위의 사후 진단, 적은 시장 국면 수, 누적 탐색의 과적합 가능성은 남는다. 로컬 원천 자료는 Git에 포함하지 않아 공개 저장소만으로 모든 API 원문을 복원할 수 없다.
