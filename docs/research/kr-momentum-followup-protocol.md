# 20봉 모멘텀의 추가 탐색 검증

거래대금 100종목군의 개발 구간에서 고변동성 횡단면 모멘텀은 20봉 +12.46%, 40봉 +6.36%, 60봉 +21.64%였다. 40봉 기본값은 같은 구간 NDX를 넘지 못했고, 60봉에는 미해결 기업행위 보유가 있었다. 따라서 기존의 **기본값 중심 사전 통과 기준을 만족한 가족은 아니다.**

다만 사용자가 요청한 파라미터 탐색의 결과로 20봉은 확인할 가치가 있다. 2020년 이후 이 종목군·가족의 성과를 보기 전에 다음 추가 확인을 고정한다.

- 관심 후보는 20봉·최근 제외 0봉·상위 5종목·VIX 25 이상이다. 다른 조건은 거래대금 100종목 실험과 같다.
- 2020–2022와 2023–2026-08-28에 20·40·60봉을 모두 실행하되, 후속 결과를 보고 관심 후보를 다른 봉 수로 바꾸지 않는다.
- 원래 사전 선택 기준의 통과로 표현하지 않는다. 중간·마지막 두 구간의 성과, 표본 수, 파라미터 이웃, 기업행위, 비용을 보고 추가 탐색 후보로 판단한다.
- 20봉의 최종 구간에서는 비용 배수 2·4와 시드 7·42를 적용한다. 필요하면 동일 입력 재실행으로 실제 계산 결과가 같은지 확인한다.

이는 개발 구간에서의 추가 파라미터 선택이며 다중 탐색 위험이 증가한다. 이후 기간으로 20봉을 고른 것이 아니라는 점과 최초 프로토콜 미통과를 함께 기록한다.
