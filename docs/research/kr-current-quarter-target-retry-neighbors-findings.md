# 재개 정책의 인접 파라미터와 현재 종목군 확인

2026-09-09 작성, 가격·거시 판단 기준은 2026-09-08 종가다. 기준 커밋 `c6d7e78`에서 [사전 규칙](kr-current-quarter-target-retry-neighbors-protocol.md)을 고정하고 여섯 후보·두 단계의 462개 새 계좌를 계산했다. 기본 재개 정책 77개는 같은 날짜 대조에 재사용했다.

**인접 파라미터 확인은 통과하지 못했다.** 15봉 회전의 최근 비중첩 성공이 2/4로 과반에 못 미쳤다. 다른 다섯 후보가 통과했어도 전체 통과로 표시하거나 가장 좋은 후보로 기본값을 바꾸지 않는다. 현재 종목군 선정 시점을 과거 월별 규칙과 맞추는 수정은 완료했고 상위 5종목은 같았다. 자동매매 투입 전략은 아직 확정하지 않았다.

## 고정 설정과 전체 결과

기본은 20일 수익률 상위 5종목·20봉 회전이며 양수 모멘텀·skip 0·미확인 사건 이후 이력 제한을 유지한다. 한 번에 선정 기간 21·25일, 보유 수 4·6개, 회전 주기 15·25봉 중 하나만 바꿨다. 운영 전략과 거래 코드는 변경하지 않았다.

초기 1억원, 평가 목표 +10.5%·실제 비용 후 목표 +10%, 원래 최고점 대비 −15% 중단, 달력 3개월 만기다. 목표 청산을 마친 실제 현금이 +10% 미만이면 원래 전략 일정에 따라 재개한다. 수수료 1.5bp·날짜별 매도세·편도 슬리피지 5bp·직전 거래량 1% 체결 한도, 시드 204·일정 이동 0을 고정했다. 자금·중단 기준은 연구 가정이며 15%가 실제 손실 상한은 아니다.

진입 조건은 코스피 20일 연율 변동성 30% 이상·20일 수익 양수·20일 평균 위다. 검증 19개와 최근 58개는 서로 겹치는 시작일을 포함한다. 비중첩은 첫 적격 시작일부터 만기가 겹치지 않도록 고른 동일 규칙이다. 두 단계 모두 전체 성공 과반·수익 중앙값 10% 이상·비중첩 성공 과반이어야 후보별 진행 기준을 통과한다.

## 15봉 회전이 실패한 경로

최근 비중첩 네 계좌의 수익은 시작일 순으로 2024-09-02 −8.36%, 2025-04-28 +11.02%, 2025-11-17 +13.13%, 2026-02-19 −10.17%다. 중앙값은 +1.33%다. 특히 첫 계좌는 기본 20봉 회전의 +12.90%에서 −8.36%로 바뀌었다.

두 설정은 2024-09-04에 같은 다섯 종목을 매수했다. 최초로 평가액이 달라진 날은 09-27이다. 기본은 10-08에 기존 종목을 매도하고 10-10에 다음 종목군을 매수한 뒤 10-29 목표 청산을 완료했다. 15봉 설정은 09-27부터 교체하고 09-30에 매수했으며, 이후 두 차례 더 교체한 뒤 11-22 낙폭 중단 신호·11-25 청산으로 끝났다. 추가 체결은 20건, 추가 모형 비용은 820,238원이다.

**이 계좌는 두 설정 모두 목표 미달 후 재개가 한 번도 없었다.** 재개 규칙만 바꿔 해결할 수 있는 실패가 아니다. 교체 날짜와 그때의 순위·종목군 노출이 달라진 사례다. 순위 변화에 따른 잦은 교체를 줄이는 방식은 후속 가설이 될 수 있지만 아직 결과로 확인하지 않았다. [실패 설정의 네 경로](kr-current-quarter-target-retry-neighbors-results/failed-setting-audit.json)에 체결·위험 사건·최초 차이·비용을 보존했다.

## 현재 종목군을 과거 월별 기준에 맞춘 결과

이전 현재 관찰은 09-07까지의 자료로 종목군을 새로 선정했다. 과거 생성기 `ebc7936`은 매월 첫 거래일에 전 거래일까지의 시가총액·실제 20일 평균 거래대금으로 종목군을 고르고 월중 유지한다. 선택 결과를 5봉 간격 원본 일정에 게시하며 계좌 전략은 전 거래일에 유효한 종목군을 조회한다.

저장 원본의 2015-01-19 일정 기준점을 보존하고, 검증된 2026-08-14 이후 결손 실제 거래일 08-18·19·20·24를 기존 수집 자료로 채웠다. 현재 거시 달력과 겹치는 2015-02-02부터 08-14까지의 거래일은 원본과 일치했다. 09-08 신호가 조회하는 날짜는 09-07, 확장한 원본의 마지막 게시 일정은 09-01, 해당 월 종목군의 선정 자료 시점은 **08-31**이다. 현재 선정 과정만 수정했으며 이번 과거 계좌의 입력·시작일은 바꾸지 않았다.

`select_current_krx.py`에 `--universe-asof`를 추가해 신호일과 종목군 선정 시점을 분리했다. 저장된 월말 시가총액과 당시 알려진 보통주·상장 상태를 사용하고, 실제 20거래일 자료를 확인한다. 옵션을 생략한 이전 현재 선정 결과는 바이트까지 동일하다.

공통 196종목이며 월말 기준에서는 동진쎄미켐·영원무역홀딩스·SK가스·한전KPS가 빠지고 신영증권·GS리테일·클래시스·에스티팜이 들어온다. 월말 기준 200종목 모두 평균 거래대금 10억원 이상을 충족한다. 새로운 현재 입력은 실제 일봉 50,186개이며 미확인 사건에 대한 이력 제한 10건을 유지한다.

## 검증과 남은 판단

새 집계는 539개 원본 계좌와 14개 요약의 해시·고정 후보·비용·시드·만기·목표 판정·최고점 기준 낙폭을 대조한다. 다른 전략 파라미터끼리 비교할 때만 재개 이전 체결 경로 동일성 검사를 적용하지 않는다. 현금·전량 청산·위험 사건·재개 경계 검사는 그대로 적용한다. 기존 재개 비교 539쌍도 변경한 집계기의 기본 동작으로 다시 감사해 이전 집계 결과와 일치하는지 확인한다.

현재 선정의 기본 날짜·월말 날짜·미래 및 휴장일 거부·저장 월말 시가총액과 당시 분류를 확인하는 Python 테스트 4개를 통과했다. 변경 Python 파일의 컴파일과 집계를 확인했다. 거래 TypeScript와 기존 테스트는 `bb6af78`과 같아 당시 통과한 27개 테스트·ESLint·서버 타입 검사 및 기본 결과 재현의 적용 범위는 유지된다. 이번에 거래 테스트를 새로 실행한 것으로 표시하지 않는다. 정확한 검증 결과는 [검증 기록](kr-current-quarter-target-retry-neighbors-results/verification.json)에 있다.

앞선 [과거 구간 실패](kr-current-quarter-target-retry-diagnostics-findings.md)와 재개 후 이익 상실 사례는 남는다. 현재와 닮은 회복 조건의 비중첩 표본은 검증·최근 각 1개, 수출 성장까지 합치면 각 0개다. 원래 현재 환경 판정에 필요한 단계별 비중첩 10개 기준을 충족하지 못한다. 이번 462개는 같은 역사에서 파라미터를 바꾼 반복 계좌로 독립 표본이 늘어난 것이 아니다. 여러 번 탐색한 검증·최근 구간을 새로운 미사용 평가로 표현하지 않는다. 거시 자료의 당시 발표본 인증과 기업행위 불확실성도 남으며 실주문은 보내지 않았다.
