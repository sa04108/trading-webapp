# 백테스트 경고 그룹핑·페이지네이션 설계

날짜: 2026-07-30
상태: 승인됨 (구현 전)

## 배경

백테스트 상세의 경고·한계 섹션(`RunMetadataCard`)은 `warningsJson` 배열을
평면 목록으로 전부 그린다. 분봉 고회전 실행에서는
`${symbol} 매수 거부: 현금 부족 (ISO시각)` 이 수백 건 쌓여 다른 경고를 묻는다.

## 범위

프론트엔드만. 엔진·DB·API 무변경 — 기존 저장된 실행에 바로 적용된다.
엔진 쪽 접기(buysDroppedByCap 방식)는 하지 않는다: 과거 실행에 소급되지 않고
시점·종목 상세를 저장 단계에서 잃는다.

## 설계

### 그룹핑 헬퍼

`src/web/features/backtests/warning-groups.ts`:

- `groupWarnings(warnings: readonly string[]): Array<{ label: string; count: number }>`
- 정규화 키 = 메시지에서 ISO 타임스탬프 괄호(`(2026-01-03T…Z)`)를 지우고,
  종목 코드 프리픽스(`^[A-Za-z0-9._-]{1,20} `)를 지운 문자열.
  한글로 시작하는 1회성 요약 라인은 두 패턴에 걸리지 않아 자기 자신이 키다.
- 표시 라벨: count > 1 이면 `정규화 메시지 (N건)`, count = 1 이면 **원본** 그대로.
- 그룹 순서 = 각 키의 첫 등장 순서.

### UI (경고·한계 Alert 내부)

- 체크박스 `묶어 보기` — **기본 켜짐**. 끄면 원본 라인 전체를 페이지네이션으로.
- 페이지네이션: 거래 내역과 같은 이전/다음 버튼 + `N 페이지` 표기.
  묶기 켜짐/꺼짐 양쪽 모두 적용.
- 페이지당 표시 수 숫자 입력, 기본 20, 1~200 클램프.
- 묶기 토글·페이지당 수 변경 시 1페이지로 리셋.
- 상태는 컴포넌트 로컬 (URL·저장 없음).

## 테스트

`tests/unit/warning-groups.test.ts`:

- 현금 부족 다건이 한 그룹으로 묶이고 건수가 맞다 (종목·시각 달라도).
- 1회성 요약 라인은 원본 그대로 count 1 로 남는다.
- 그룹 순서가 첫 등장 순서를 따른다.
- 빈 배열이면 빈 배열.

페이지 계산은 slice 뿐이라 컴포넌트 로컬로 두고 수동 확인한다.
